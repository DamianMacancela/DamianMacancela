## 🚀 Proyectos Destacados

### 🕵️ [Pentest Lab Write-up](https://github.com/DamianMacancela/pentest-lab-writeup)
**Descripción:** Informe técnico de intrusión ética en un entorno controlado. Documenta el ciclo completo desde el reconocimiento (Nmap), la explotación de inyecciones SQL (Burp Suite, SQLmap), escalada de privilegios y su posterior remediación de código.
- **Stack:** Nmap, Burp Suite, SQLi, OWASP WSTG v4.2.

### 🤖 [Phishing Detector IA](https://github.com/DamianMacancela/ai-phishing-classifier)
**Descripción:** Modelo de Machine Learning (NLP) desarrollado en Python para la detección y clasificación automática de correos maliciosos (Phishing) usando TF-IDF y algoritmos Naive Bayes.
- **Stack:** Python, scikit-learn, Machine Learning.

### ⚖️ [Toolkit LOPDP · EIPD](https://github.com/DamianMacancela/lopdp-eipd-toolkit)
**Descripción:** Plantilla estructurada y genérica para la elaboración de Evaluaciones de Impacto en Protección de Datos (EIPD/DPIA), adaptada estrictamente a la normativa legal del Ecuador (LOPDP).
- **Stack:** Legal Tech, Compliance, Gestión de Riesgos.
