### Herramientas & Investigación

* **[EntraHunt](https://github.com/DamianMacancela/EntraHunt)** 
  Motor de Threat Hunting con triaje de IA para Microsoft Entra ID. (PowerShell / Microsoft Graph API)
* **[HuntKit](https://github.com/DamianMacancela/HuntKit)** 
  Toolkit avanzado de persistencia en Windows para operaciones de Red/Blue Team.
* **[crypto-shield](https://github.com/DamianMacancela/crypto-shield)** 
  Herramienta CLI para cifrado de archivos en Python usando AES-256-GCM y PBKDF2.
* **[pentest-lab-writeup](https://github.com/DamianMacancela/pentest-lab-writeup)** 
  Explotación manual (SQLi, Fuzzing) de aplicación vulnerable propia bajo metodología OWASP WSTG v4.2.
* **[ai-phishing-classifier](https://github.com/DamianMacancela/ai-phishing-classifier)** 
  Detección de phishing usando modelos de Machine Learning clásicos (TF-IDF + Naive Bayes).
* **[lopdp-eipd-toolkit](https://github.com/DamianMacancela/lopdp-eipd-toolkit)** 
  Plantillas en Markdown puro para Evaluaciones de Impacto en Privacidad (EIPD / ISO 29134).
